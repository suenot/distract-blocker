# Distract Blocker logo v2: the owl guardian

**Idea.** A small owl that keeps watch over your focus. Owls are quiet and patient, so the character says
"not now" kindly instead of shouting "stop". The head outline (two ear tufts, tapering to a point) doubles
as a shield, so the icon is both the character and the guard sign. The mascot holds a shield with a pause
mark, not a prohibition sign: a pause, not a ban.

**Files.** `icon.svg` (512x512, no background tile, reads at 16 px), `mascot.svg` (viewBox `0 0 200 220`,
`m-*` animation hooks; sleep parts are hidden by `display="none"` attributes that host CSS can override),
`wordmark.svg` (icon plus text in a system font stack, all red so it works on light and dark).

**Colours.** Brand red `#e63946` (body, text) and dark red `#b3001b` (wings). Night navy `#1d3557`
(eyes, shield): a calm counterweight to the red. Warm amber `#f4a261` (beak, feet).
Cream `#fff6ea` (face, belly) is the neutral used instead of pure white.
